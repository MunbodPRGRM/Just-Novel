# Just Novel

เว็บอ่านนิยายส่วนตัว — อ่านเนื้อหาตรงจากไฟล์ `.md` ในโปรเจกต์ ไม่มีฐานข้อมูล ไม่มีระบบล็อกอิน

## Stack

- Next.js 14 (App Router) + TypeScript + Tailwind CSS
- เนื้อหานิยาย: อ่านจากไฟล์ `.md` ด้วย `fs` + `gray-matter`
- reading progress / notes / dark mode / ขนาดฟอนต์: เก็บใน `localStorage` ฝั่ง browser
- Deploy: Vercel

## เริ่มรันในเครื่อง

```bash
npm install
npm run dev      # http://localhost:3000
```

| script | ทำอะไร |
| --- | --- |
| `npm run dev` | รัน dev server |
| `npm run build` | build production (รันก่อน push ทุกครั้ง) |
| `npm run start` | รัน build ที่ได้ |
| `npm run lint` | ตรวจ ESLint |

ไม่ต้องตั้ง environment variable ใดๆ

## ค้นหาเนื้อหา

กดไอคอนแว่นขยายบนแถบบน หรือเข้า `/search?q=คำที่หา` ตรงๆ

- ค้นทั้งเนื้อเรื่อง ชื่อตอน และข้อมูลของนิยาย (ชื่อเรื่อง/ชื่อรอง/คำโปรย/แท็ก)
- จับแบบ **สตริงย่อยทั้งวลี** ไม่ตัดคำและไม่แยกเป็นหลายคำ (ภาษาไทยไม่มีช่องว่างระหว่างคำ) — ตัวพิมพ์เล็ก/ใหญ่ของอังกฤษไม่มีผล
- เข้าจากหน้าเรื่อง/หน้าอ่าน จะค้นเฉพาะเรื่องนั้นให้ก่อน (สลับเป็นทุกเรื่องได้ในหน้าผลลัพธ์)
- ผลลัพธ์ลิงก์ไปถึงย่อหน้าที่เจอ (`#block-N`) และย่อหน้านั้นจะกระพริบให้เห็น
- แสดงสูงสุด 3 ตัวอย่างต่อตอน และหยุดกวาดที่ ~300 จุด (แก้ค่าได้ที่หัวไฟล์ `lib/search.ts`)

ยังไม่มี search index — กวาดไฟล์ `.md` ใหม่ทุกครั้งที่ค้น หน้านี้จึงเป็นหน้าเดียวที่เรนเดอร์ตอน
request (หน้าอื่น static หมด) และต้องประกาศ `outputFileTracingIncludes` ใน `next.config.mjs`
เพื่อให้โฟลเดอร์ `content/` ติดไปกับ serverless function บน Vercel ด้วย

## โครงสร้างเนื้อหา

```
content/
  <novel-slug>/
    novel.json     # metadata ของเรื่อง
    ตอนที่1.md
    ตอนที่2.md
```

### `novel.json`

| field | ความหมาย |
| --- | --- |
| `title` | ชื่อเรื่องที่แสดงบนเว็บ (จำเป็น) |
| `subtitle` | ชื่อรอง เช่น ชื่อโรมาจิ |
| `author` | ผู้แต่งต้นฉบับ |
| `translator` | ผู้แปล |
| `synopsis` | คำโปรย |
| `status` | `ongoing` \| `completed` \| `hiatus` |
| `tags` | อาร์เรย์ของแท็ก |

### ไฟล์ตอน

- ชื่อไฟล์ต้องมีตัวเลขตอนอยู่ในนั้น (`ตอนที่7.md`) — ตัวเลขตัวแรกที่เจอใช้เป็นเลขตอนและเป็น URL
- บรรทัด `# ...` ตัวแรกในไฟล์ถือเป็นชื่อตอน (จะไม่ถูกแสดงซ้ำในเนื้อหา)
- ย่อหน้าคั่นด้วยบรรทัดว่าง, `---` บรรทัดเดียวคือเส้นคั่นฉาก
- ใส่ frontmatter `title:` เพื่อ override ชื่อตอนได้

## เพิ่มตอน / เพิ่มเรื่องใหม่

1. วางไฟล์ `.md` ใน `content/<novel-slug>/` (เรื่องใหม่ต้องมี `novel.json` ด้วย)
2. commit แล้ว push → Vercel redeploy อัตโนมัติ

ไม่มีหน้า admin สำหรับอัปโหลดเนื้อหา — เพิ่มตอนคือแก้ไฟล์ในโปรเจกต์เท่านั้น

## ข้อมูลส่วนตัวในเบราว์เซอร์

ไม่มี DB — ทุกอย่างอยู่ใน `localStorage` ของเครื่องที่เปิดอ่าน

| key | เก็บอะไร |
| --- | --- |
| `just-novel:prefs` | ธีม, ขนาดตัวอักษร, ระยะห่างบรรทัด, ฟอนต์เนื้อเรื่อง |
| `just-novel:progress` | ตำแหน่งอ่านล่าสุดต่อตอน + ตอนล่าสุดต่อเรื่อง |
| `just-novel:notes` | ไฮไลต์และโน้ต (ผูกกับ ตอน + ย่อหน้า + ช่วงตัวอักษร) |

- คืนค่าการแสดงผลเริ่มต้น: ปุ่ม “คืนค่าเริ่มต้น” ในแผงตั้งค่าการอ่าน
- ล้างตำแหน่งอ่านของเรื่องหนึ่ง: ปุ่ม “ล้างประวัติการอ่านเรื่องนี้” ท้ายสารบัญ (โน้ตไม่หาย)
- ลบโน้ต: กด “ลบ” ในแผงโน้ต หรือคลิกที่ไฮไลต์ในหน้าอ่าน

ค่าที่อ่านจาก `localStorage` ถูกตรวจ/บีบช่วงใหม่ทุกครั้ง (`lib/storage.ts`) — ข้อมูลพังหรือถูกแก้มือ
จะถอยไปใช้ค่าเริ่มต้นแทนที่จะทำให้หน้าพัง

## ข้อจำกัดที่รู้ตัว

- ไม่มี auth: ใครมีลิงก์ก็เข้าได้ (ไม่ประกาศเว็บ + ปิด SEO ด้วย `robots: noindex`)
- `localStorage` ผูกกับเบราว์เซอร์นั้นๆ — ตำแหน่งอ่านล่าสุด/โน้ตไม่ sync ข้ามเครื่อง
- เพิ่มตอนต้อง redeploy เสมอ
