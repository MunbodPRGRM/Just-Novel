# ตอนที่ 81: ความห่วงใยของพ่อ (1) (เริ่มเล่มสอง)

ณ นครหลวงแห่งจักรวรรดิวาเลเรีย เด็กสาวผมสีเงินตาสีแดงผู้งดงามนั่งอยู่ที่โต๊ะเขียนหนังสือ

แขนข้างหนึ่งเท้าเอียงๆ หลังมือรองแก้มไว้เบาๆ ส่วนขาเรียวได้สัดส่วนที่สวมถุงน่องไหมสีดำแนบชิดกันอย่างเป็นธรรมชาติ

ดวงตาของเธอจดจ่ออยู่กับหนังสือหนังแกะตรงหน้า

ผ่านมาสามวันแล้วนับจากศึกในดันเจี้ยนใต้ดิน หลังพักผ่อนไปช่วงสั้นๆ แอสทริดก็กลับมาศึกษาเวทมนตร์ที่ไม่มีวันจบสิ้นอีกครั้ง

ตอนนี้เธอเริ่มศึกษาวงเวทอย่างเป็นระบบ ตามที่ชาร์ล็อตต์เคยแนะนำไว้

พลังจิตที่สะสมไว้ยังอยู่แค่ระดับนักเวทฝึกหัดขั้นต้น พอจะร่ายเวทน้ำแข็งขั้นกลางซึ่งเป็นธาตุที่เธอเข้ากันได้ดีที่สุดได้อย่างหวุดหวิด แต่เธอรู้ว่าถ้ายังวนเวียนอยู่กับเวทขั้นต้น ก็จะไม่ก้าวหน้าไปไหนมากนัก

มีแต่จะเปลืองแรงเปล่าๆ

สิ่งที่เธอขาดในตอนนี้ไม่ใช่ความเข้าใจในเวท แต่เป็นปริมาณพลังจิตทั้งหมดที่มี

การขัดเกลาพลังจิตเป็นกระบวนการยาวนาน เห็นผลชั่วข้ามคืนไม่ได้ แอสทริดจึงตัดสินใจว่าศึกษาวงเวทล่วงหน้าไว้ก่อนดีกว่านั่งรอเฉยๆ

ถือเป็นการปูพื้นฐานสำหรับการเรียนขั้นต่อไป

ก่อนหน้านี้ แอสทริดเคยลองสลักวงเวทมาบ้างแล้ว เช่น วงเวทเปิดปิดที่ใช้กับน้ำหอม หรือเวทคลังพลังจิตที่ชาร์ล็อตต์สอน

อย่างหลังเองก็มีโครงสร้างที่เกี่ยวข้องอยู่ด้วย

ทว่าวงเวทเหล่านั้น ถ้าไม่ใช่สิ่งที่เธอคิดออกเองจากวาจาบรรพชน ก็เป็นสิ่งที่คนอื่นสอนให้ ต้องลอกเลียนด้วยมือตามแบบ

ยังมีรายละเอียดซับซ้อนอีกมากที่เธอต้องแยกแยะและทำความเข้าใจด้วยตัวเอง

“ความรู้เบื้องต้นว่าด้วยวงเวทและหลักสำคัญในการร่ายเวทขั้นกลาง” หนึ่งในตำราล้ำค่าของหอสมุดหลวงแห่งวาเลเรีย วิเคราะห์กระบวนการไหลเวียนของพลังจิตและแก่นแท้ของวงเวทไว้อย่างลึกซึ้งแต่เข้าใจง่าย

มันช่วยแอสทริดได้มหาศาล

แสงแดดสองสามสายลอดผ่านผ้าม่านลงบนเตียงสีม่วงไลแลค ในห้องนอนอันเงียบสงัดเหลือเพียงเสียงลมหายใจแผ่วเบาของเด็กสาว กับเสียงพลิกหน้ากระดาษเป็นครั้งคราว

อัศวินใช้พลังจิตเสริมร่างกายและเพิ่มความคมให้การโจมตี ส่วนผู้ใช้เวทเชี่ยวชาญการร่ายเวทเพื่อควบคุมพลังของธาตุให้ใช้งานได้หลากหลาย

ระหว่างร่ายเวท พลังจิตจะแปรสภาพเป็นพลังงานอีกรูปแบบหนึ่งที่สามารถนำทางอนุภาคธาตุได้

การแปรสภาพนี้ย้อนกลับไม่ได้ ต่อให้ยังไม่มีธาตุใดเข้ามาเกี่ยวข้องก็ตาม

หลักข้อนี้แสดงให้เห็นว่า เมื่อเริ่มร่ายเวทไปแล้ว การหยุดกลางคันจะเรียกพลังจิตคืนกลับมาไม่ได้แม้แต่น้อย

ผลข้อนี้เห็นชัดเป็นพิเศษในวงเวท หากการส่งพลังจิตถูกตัดขาดกะทันหัน พลังเวทที่แปรสภาพไว้แล้วในวงเวทจะไม่อาจไหลไปตามทางที่กำหนดได้อีก

ผลที่ตามมาจึงเหลือเพียงสองทาง

ทางแรก ผู้ใช้เวทที่มีประสบการณ์สามารถใช้เทคนิคต่างๆ ระบายธาตุส่วนเกินออกสู่อากาศได้อย่างปลอดภัย

ทางที่สองซึ่งอันตรายกว่ามาก คือวงเวทล้มเหลว จนอาจทำให้ธาตุปั่นป่วนวุ่นวาย

ในกรณีนี้ พลังเวทที่ควบคุมไม่ได้มักจะซัดย้อนกลับเข้าหาผู้ร่าย

และเพราะมันเข้ากับพลังจิตไม่ได้ ผลที่ได้คืออาการพลังจิตตีกลับ ซึ่งในการต่อสู้อาจร้ายแรงถึงขั้นเสียชีวิต

ตอนอ่านมาถึงย่อหน้านี้ แอสทริดสังเกตว่าตัวอักษรพิมพ์ด้วยหมึกตัวหนา บ่งบอกว่าเป็นเรื่องสำคัญ

ก่อนหน้านี้เธอเคยเจอแต่คาถาวาจาบรรพชนขั้นกลาง แล้วลองร่ายออกไปตรงๆ เลย

เธอไม่รู้มาก่อนเลยว่ากระบวนการนี้อันตรายถึงเพียงนี้

มิน่าเล่า ตอนชาร์ล็อตต์รู้ว่าแอสทริดแยกโครงสร้างวงเวทออกมาเอง ถึงได้มีปฏิกิริยารุนแรงขนาดนั้น

นักเวทฝึกหัดขั้นสูงสุดทั่วไป เวลาลองร่ายเวทขั้นกลาง มักมีผู้คุ้มกันคอยเฝ้าอยู่ข้างกายเพื่อป้องกันอุบัติเหตุ

แต่แอสทริดอาศัยแค่การอ่านภาษาอังกฤษออก ก็ทำสำเร็จได้ในครั้งเดียว โชคดีที่ไม่มีอะไรผิดพลาด

การสวดคาถาไม่ได้มีไว้เพียงเรียกธาตุ แต่ยังช่วยปกป้องขั้นตอนสำคัญที่พลังจิตแปรสภาพเป็นพลังเวทด้วย

ช่วยกันการรบกวนจากภายนอก และทำให้การแปรสภาพมีประสิทธิภาพยิ่งขึ้น

เมื่อถึงขั้นจอมเวท ผู้ใช้เวทจะไม่ต้องเปล่งคาถาออกเสียง แต่ท่องคาถาในใจแทนได้

วิธีนี้ป้องกันไม่ให้คู่ต่อสู้ที่แข็งแกร่งคาดเดาความเคลื่อนไหวถัดไปได้

ความผันผวนของธาตุในอากาศมักตรวจจับได้อยู่แล้ว วิธีนี้จึงไม่ได้ผลเสมอไป

แต่บางครั้งก็ได้ผลเหนือคาดกับศัตรูที่ไม่เข้าใจเวทมนตร์

ยกตัวอย่างเช่น การมองเห็นธาตุสามารถจับได้ว่ามีธาตุน้ำแข็งกำลังรวมตัวกันในอากาศ

แต่เพราะไม่ได้สวดคาถาออกเสียง คู่ต่อสู้จึงบอกไม่ได้ทันทีว่า ในช่วงเริ่มก่อวงเวท ผู้ร่ายกำลังเตรียมปล่อยเวทโล่เยือกแข็งหรือศรน้ำแข็ง ทำให้ตั้งรับล่วงหน้าได้ยาก

การร่ายคาถาในใจอาจมีประโยชน์จำกัดสำหรับคนอื่น แต่สำหรับแอสทริดแล้ว มันมีความหมายอย่างยิ่ง

เทคนิคนี้ทำให้เธอใช้คาถาโบราณที่ทรงพลังกว่าได้ โดยไม่ต้องกลัวว่าความลับจะรั่วไหลถึงหูคนนอก

อ่านต่อไป แอสทริดก็มาถึงหมวดที่เธอชอบเป็นพิเศษ หมวดเทียบคาถาโบราณกับวงเวท ซึ่งสำหรับเธอก็คือภาษาอังกฤษเทียบภาษาอังกฤษนั่นเอง

ในหมวดนี้มีเวทหลายบทสาธิตไว้พร้อมคาถาโบราณ วงเวทที่คู่กันก็ค่อนข้างเรียบง่าย ศึกษาไม่นานก็เข้าใจ

เวลาผ่านไปทีละนาทีจนใกล้เที่ยง เอลิสก็มาเคาะประตู แจ้งแอสทริดว่าเมดเตรียมอาหารกลางวันไว้แล้ว ขอให้รีบไปทานก่อนอาหารจะเย็น

“คุณหนูแอสทริด ยังมีอีกเรื่องที่ต้องเรียนให้ทราบค่ะ” เอลิสพูด หลุบตาลงขณะจัดโบว์ที่คอเสื้อของแอสทริดให้อย่างแผ่วเบา “ฝ่าบาทประสงค์จะพบคุณหนูบ่ายนี้ ที่สวนด้านหลังพระราชวังค่ะ”

จักรพรรดิฮิบบอร์ตอยากพบเธออย่างนั้นหรือ

ได้ยินดังนั้น สีหน้าของแอสทริดก็ครุ่นคิด

เธอหันไปมองไลราที่ยืนเงียบๆ อยู่ใกล้ๆ

สายตาที่ค่อนข้างเย็นชาทำให้ไลรายืดตัวตรงโดยสัญชาตญาณ มือเรียวประสานกันเรียบร้อยไว้ตรงหน้ากระโปรง

แม้ไลราจะรู้ว่าองค์หญิงแอสทริดมีจิตใจดี แต่กลิ่นอายสูงศักดิ์ที่แผ่ออกมาโดยธรรมชาติยังคงกดดันเธออย่างหนัก จนยากจะสบตาตรงๆ

“รู้แล้ว” แอสทริดตอบเบาๆ

หลังอาหารกลางวัน ทั้งสามก็มุ่งหน้าไปยังสถานที่นัดพบที่จักรพรรดิฮิบบอร์ตกำหนด

แอสทริดสั่งให้เอลิสกับไลรารออยู่ห่างๆ ก่อนจะก้าวเข้าสวนด้านหลังไปคนเดียว

แม้จะเรียกว่าสวน แต่ที่นี่ไม่ได้มีดอกไม้เต็มไปหมด กลับประดับด้วยรูปปั้นและภาพสลักนูนต่ำ

ใกล้น้ำพุกลางสวน ชายวัยกลางคนผมทองตาสีเขียวอมฟ้านั่งไขว่ห้างอยู่

เขาสวมเสื้อคลุมหลวมๆ สีบรอนซ์ทับเสื้อตัวในสีขาวเรียบกับกางเกง บนบ่ามีนกอินทรีขนสีเข้มปีกลายจุดขาวเกาะอยู่

ได้ยินเสียงฝีเท้าใสกังวาน ฮิบบอร์ตก็ลืมตาขึ้น เห็นแอสทริดกำลังเดินเข้ามา

สีหน้าเคร่งขรึมเด็ดขาดที่เขามักแสดงในห้องว่าราชการเลือนหายไป แทนที่ด้วยความเอ็นดูอย่างจริงใจ

“สวัสดีตอนบ่ายค่ะ เสด็จพ่อ” แอสทริดก้มศีรษะคำนับเล็กน้อยอย่างสุภาพ น้ำเสียงอ่อนโยนและนอบน้อม

“ลุกขึ้นเถิด มานั่งข้างพ่อ” ฮิบบอร์ตตอบ น้ำเสียงสงบ

เห็นว่าม้านั่งมีที่พอสำหรับสองคน แอสทริดก็ทำตาม นั่งลงห่างจากฮิบบอร์ตราวครึ่งช่วงตัว

ระยะห่างนี้ไม่สนิทชิดเชื้อเกินไปและไม่ห่างเหินเกินไป สะท้อนความสัมพันธ์อันพิเศษระหว่างคนทั้งสอง

ทันทีที่แอสทริดนั่งลง นกอินทรีบนบ่าของฮิบบอร์ตก็กระพือปีกทะยานขึ้นฟ้า

ชั่วพริบตาก็เหลือเพียงจุดดำเล็กๆ ก่อนจะหายลับไปในที่สุด

“ลูกรบกวนมันหรือเปล่าคะ” แอสทริดถามเบาๆ

ฮิบบอร์ตส่ายหน้า “เปล่า มันพักพอแล้ว แค่อยากออกไปกางปีกเท่านั้น”

แอสทริดเหลือบมองชายข้างกาย ผมสีทองและแสงแดดที่ขับโครงหน้าคมเข้มให้เด่นชัด เงียบไปครู่หนึ่งก่อนจะพูดขึ้นอีกครั้ง

“เสด็จพ่อมีเรื่องอะไรจะบอกลูกหรือเปล่าคะ”

ในความทรงจำของแอสทริด แม้จักรพรรดิฮิบบอร์ตจะรักใคร่เอ็นดูเธอมาก แต่แทบไม่เคยเรียกพบเป็นการส่วนตัว

ทั้งปีมีเพียงไม่กี่ครั้งเท่านั้น

การเรียกพบกะทันหันวันนี้ น่าจะหมายความว่ามีเรื่องสำคัญต้องคุยกัน

ฮิบบอร์ตพยักหน้า มือลูบคทาไปมาอย่างไม่ได้ตั้งใจ คทาลายดอกสายน้ำผึ้งนี้คือสัญลักษณ์แห่งอำนาจและระเบียบ เขาพูดด้วยน้ำเสียงหนักแน่น

“พ่อสั่งให้สืบแหล่งที่มาของอาหารทะเลทุกเจ้าในตลาดอย่างละเอียด ตรวจสอบทุกคนที่น่าสงสัยในวัง แต่ถึงจะทำขนาดนั้น ข้อมูลที่เป็นประโยชน์ก็ยังมีน้อยมาก”

ถ้ามีใครสามารถเอาของที่ทำให้แพ้ไปใส่ในจานขององค์หญิงได้ คนผู้นั้นต้องเป็นคนรับใช้หรือเมดที่ใกล้ชิด

หากเอลิสไม่ได้ผูกพันกับแอสทริดราวพี่น้อง ฮิบบอร์ตอาจสงสัยแม้กระทั่งเธอ

“อย่างนั้นหรือคะ” แอสทริดพึมพำ ขนตายาวทอดเงาจางๆ เมื่อเธอหลุบตาลง

ฮิบบอร์ตพินิจใบหน้าด้านข้างอันบอบบางของเธอ ก่อนจะพูดต่อ “ก่อนหน้านี้ลูกบอกว่าอาหารทะเลนั่นอาจมาจากท่าเรือออสต์วิก แต่ไม่ว่าจะสืบลึกแค่ไหน ก็ไม่เจอเบาะแสอะไรเลย”

ฮิบบอร์ตรู้จักแอสทริดดี เธอไม่ใช่คนหัวไวหรือเจ้าเล่ห์อะไรนัก ข้อมูลเรื่องอาหารทะเลน่าจะมาจากเอลิส

แต่พอเขาลองพิจารณาว่าใครจะได้ประโยชน์จากการกระทำนี้ คำตอบก็ชัดเจนขึ้น

หากมองจากแรงจูงใจ อลิสแตร์แทบไม่มีเหตุผลจะเล่นงานแอสทริดเลย

ข้อแรก ต่อให้ทำสำเร็จ ก็สร้างความเสียหายให้ลูคัสได้จำกัด

ข้อสอง หากความจริงถูกเปิดโปง ข้อหาทำร้ายบุตรีสุดที่รักของจักรพรรดิก็มากพอจะทำให้อลิสแตร์ถูกเนรเทศจากนครหลวงไปตลอดชีวิต

เดิมพันสูง ผลตอบแทนต่ำ ไม่มีใครที่มีสติครบถ้วน โดยเฉพาะเชื้อพระวงศ์ที่ช่ำชองอย่างเขา จะทำเรื่องโง่เขลาเช่นนี้

สรุปแล้ว ฮิบบอร์ตไม่ได้เชื่อจริงๆ ว่าอลิสแตร์อยู่เบื้องหลังเหตุการณ์นี้
